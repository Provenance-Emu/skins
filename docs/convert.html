Install your overlay

Save and extract the ZIP, then copy the whole folder into RetroArch’s overlays directory. In RetroArch, open Settings → On-Screen Overlay → Overlay Preset and choose overlay.cfg. Enable Display Overlay and adjust scale or position for your display.

On iPhone and iPad, use Files to extract and move the folder into RetroArch. On Apple TV, transfer the extracted folder through RetroArch’s file-transfer interface from another device. Apple TV uses a controller; overlay buttons are not touch controls.

Game screen placement, DS touchscreens, macros and emulator-specific actions may need manual configuration. A single overlay cannot arrange two DS screens separately. Choose the matching device layout for best results.
