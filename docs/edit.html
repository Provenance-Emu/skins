Edit a Skin

Move and resize a skin's buttons and screens on a device frame, change its fields and artwork, and download a working .deltaskin or .manicskin. Everything runs in this page. Nothing is uploaded.

1 — Pick a skin

This is a read-only view on iPhone: the canvas and the panels do not fit together. Open the page on a desktop or an iPad to edit. To adjust a button on your phone, use Edit controls in the app.

Screen input frame

The part of the emulator's picture this screen shows, on a strip of the system's native resolution.

Arrow keys nudge the selected button or screen by 1 point, Shift by 10. Hold Alt while dragging to skip snapping, Shift while resizing to lock the aspect. Cmd/Ctrl+Z undoes, Delete removes the selected button.

After you download

  • The file is named for the skin's identifier. If you changed what the skin is called, change the identifier too: Manic will not import a second skin with the same one.
  • Open it in Provenance, Delta or Manic to try it. The page keeps a draft in this browser, so a reload does not lose your work; it offers to restore it, and never uploads it.
  • To publish it, host the file somewhere that serves it and submit the URL. This page only downloads.

Everything the editor does not touch (unknown info.json keys, themes, alternate layouts, per-game layouts) is written back as it was. Themes, alternate layouts and per-game layouts are listed but not editable here yet.
