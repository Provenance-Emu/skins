Skin format 2.0

Format 2.0 describes a controller as a tree of screens, controls and artwork. A compatible app resolves the tree for the current display and orientation. The same archive ships a classic layout and artwork for existing readers.

  • Schema reference for node fields, allowed values and live examples.
  • GameCube tutorial for building and baking a controller with standard parts.
  • Convert a generated controller for emulator authors moving from a generated classic layout.

What readers need

List every feature the source uses in requires, including features used inside expanded parts and variants. For example, a standard stick needs parts.std@2.0 and controls.thumbstick. The validator reports omitted capabilities. A reader can use the responsive source when it supports the format version and every required capability.

What the classic bake carries

The classic info.json has complete representations with artwork, screen frames and control hit areas. Bake both standard and edge-to-edge iPhone layouts in portrait and landscape. The baker includes skin.json and a format2 marker in the archive, so classic readers can keep using info.json.

Artwork-only themes remain classic asset overrides. Themes that move controls or screens get separate archives. A game match bakes to gameOverrides, a toggle variant to altRepresentations, and a selectable variant to its own archive.
