Build a GameCube skin

This tutorial builds a small phone controller from the standard parts. The final source includes both sticks, a D-pad, face buttons, shoulder triggers, Z and Start.

1. Anchor the game screen

Start with the screen-only source. The root group contains a screen with a 4:3 aspect ratio. In portrait, its width follows the safe area and its top stays pinned. In landscape, a when rule centers it and sets its height to 80% of the safe area. The resolver derives the width from the aspect ratio.

2. Add two control groups

Give each group a stable ID and anchor it to a bottom corner of the safe area. The frames inside a group are local to that group. Start is anchored independently to the bottom center.

3. Instantiate standard parts

Each use chooses a part, and with supplies its inputs or colors. Use leftThumbstick for the main stick and rightThumbstick for the C-stick. The same semantic names survive the classic bake.

{
  "use": "std.stick",
  "id": "c-stick",
  "with": { "input": "rightThumbstick" },
  "layout": { "frame": [76, 112, 52, 52] }
}

4. Bake and test the archive

Save the finished source and run the CLI from a SkinKit checkout. The preview above uses the same resolver as the website renderer.

xcrun swift run skinkit-bake /path/to/skin.json /path/to/output

Import the resulting .deltaskin in the target app. Check both orientations, move each stick independently and check every button against its artwork. Test the same archive in a classic reader to verify the fallback.
